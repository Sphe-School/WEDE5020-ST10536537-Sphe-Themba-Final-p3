# WEDE5020-ST10536537-Sphe-Themba-Final-p3

Big Tech Solutions

Project Overview

Big Tech Solutions is a website developed as part of the WEDE5020 Introduction to Web Development module. The website represents an IT company that provides technology-related products and services, including computer repairs, computer parts, networking and website development.

The purpose of the project is to create a user-friendly website where customers can learn about the company, explore its services, view images and contact the business.

Technologies Used

- **HTML5** – Used to structure the website pages and content.
- **CSS3** – Used to style the website and create its layout and appearance.
- **JavaScript** – Used to add interactive features and improve the user experience.
- **GitHub** – Used for storing and managing the project files.
- **GitHub Pages** – Planned platform for hosting and deploying the website.

Website Pages

The website contains the following pages:

- **Home:** Introduces Big Tech Solutions.
- **About:** Provides information about the company.
- **Services:** Displays the different services offered.
- **Gallery:** Displays images related to the company's work.
- **Contact:** Allows customers to contact the company and submit enquiries.
- **FAQs:** Provides answers to common customer questions.

Features and Improvements

The following features and improvements were added during development:

- Responsive website layout for different screen sizes.
- Improved navigation between website pages.
- Search and category filtering for services.
- Interactive gallery with a lightbox to view images.
- Contact and enquiry forms with required-field validation.
- Embedded Google Maps location.
- SEO improvements, including page titles, meta descriptions and meta keywords.
- Descriptive image alternative text (alt text).
- Cookie consent notification.
- Automatic dark mode based on the visitor's device settings.

What We Learned

During this project, we developed our understanding of:

1. **HTML:** How to structure webpages using elements, headings, images, links, forms and other HTML components.
2. **CSS:** How to style webpages, control layouts, use colours and improve the appearance of a website.
3. **JavaScript:** How to make webpages interactive using events, functions and DOM manipulation.
4. **Forms:** How to create forms, use input validation and process customer enquiries.
5. **SEO:** How page titles, meta descriptions, keywords and image alt text help improve website accessibility and search visibility.
6. **Responsive Design:** How to make websites easier to use on different devices and screen sizes.
7. **GitHub:** How to store project files, manage changes and prepare a website for deployment.
8. **Problem Solving:** How to identify website issues, debug code and improve existing functionality.
